# hl

ci/cd pipeline engine for homelab use

this is a learning project that i created in order to understand and be able to create and run ci/cd pipelines from the termianl with the single command
It allows to reuse the pipeline anywhere as long as the tool is installed and the host has the access to the targets of the configuration
it is ment to be able to set up my entire homelab with single command from the config files that are 
stored in the file structure
